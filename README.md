# Kotlin Interview Handbook

A visual, example-driven Kotlin handbook. From zero to interview ready.

**Who this is for:** experienced developers who are new to Kotlin and want to learn it properly, not just skim a cheat sheet. Unlike a terse refresher, this handbook teaches: every concept gets explained before it's demonstrated, and the "why" behind Kotlin's design choices is part of the content. Assumes programming fluency, zero Kotlin knowledge. Comparisons to Go show up throughout where the mapping genuinely helps.

## Viewing

Clone the repo and open `index.html` in your browser. No build step, no dependencies.
